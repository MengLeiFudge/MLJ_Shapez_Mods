# 十二工坊 / Twelvefold

Twelvefold 是 shapez 第一代的独立玩法模组，标识为 `mlj-twelvefold`。每层十二个 30° 槽位、四种片型、最多三层；通过切割、旋转、交换、堆叠、染色和熔炼组织工厂，最终使用电路制造自由模式 MAM 订单。

首版 `0.1.0` 按 shapez 1.5.6 的实际接口实现，已完成静态检查与构建流程。实际游玩、节奏与平衡、译文质量及界面显示尚未验证。

## 安装

1. 从打包输出目录取得 `Twelvefold.js`，或解压 `Twelvefold-<版本>.zip` 取得该文件。
2. 在 shapez 的“模组”页面点击“打开模组文件夹”，将 `Twelvefold.js` 放入该目录。
3. 重启游戏，然后新建专属 Twelvefold 存档。

只需安装 JS，图片与全部译文已内嵌。`INSTALL.txt` 提供游戏支持的全部 24 种语言的安装说明。`manifest.json` 记录版本、文件大小和 SHA-256；ZIP 旁的 `.sha256` 记录整个压缩包的哈希。

模组处于未发布草案阶段，建筑 code 与存档结构直接调整；本版存档版本为 2，请创建新档，不迁移原版、其他模组或前一版草案存档。安装包中的说明文件供离线阅读。

## 工坊界面

顶部目标栏常驻显示当期五个并行主线的小图和交付数，点击小图打开分层详情；自由模式显示当前订单。目标栏保留原版左侧目标和右上菜单的空间，窗口较窄时移到它们下方；蓝图费用或色盲提示启用时也向下避让。科研点、蓝图点和当期新能力说明一同显示。“主线”查看详细目标；“研究”打开工坊，也可按原版研究快捷键 `F`。`Esc` 或 `Q` 关闭面板。

工坊包括主线、支线、研究、蓝图、代表图形、订单和帮助。账本变化时原地更新进度、余额和购买状态；阶段或订单改变当前标签的内容结构时才重建列表，保留滚动位置。工坊、目标栏、工具栏和分层详情共用随原版明暗主题切换的配色与正文字号，背景、正文、表格和按钮均明确取色；短码始终保持固定朝向。目标、支线、代表档位和订单达标后自动结算并显示通知，研究购买由玩家选择。

开局引导按顺序显示六步：在图形矿放开采器、用带向中心交付一件图形、半切机实际产出、+30° 旋转器实际产出、查看分层详情、打开工坊。放置选择不会代替实际加工完成；每步和关闭状态均写入存档，提前做过的步骤也会记住。每个里程碑都有一句新能力介绍，注明建筑所在的大类。

将鼠标停在带上物料、机器缓存、存储、矿脉或电路图形上，按原版图形查看键 `Alt` 打开十二槽分层详情；也可点击目标或工坊里的图形。正在放置建筑、蓝图或选区时保留原版操作。

电路常量放置后打开配置。也可点击“配置”，再点击线路层上的 Twelvefold 节点，查看端口顺序并填写图形、整数、颜色、片型或布尔常量。

## 分类建筑栏

普通层数字键 `1–0` 固定选择传送带、分合流、隧道、存储、开采、切割、旋转、翻转、组合、颜色；按 `E` 后，电路层 `1–9` 选择导线、常量、传感与显示、逻辑、整数运算、分析、时序、订单、虚拟加工。多建筑大类在上方展开小类行，每格为独立建筑；七个旋转角度和两个交换规则分别占格。链式开采购买后原位升级。

再次按当前数字键，或按 `T`，选择该类下一建筑。`Tab` 在本层已解锁的大类之间轮换，保留各类上次选择。右键或 `Esc` 取消并收起；`Q` 保留吸管。未解锁建筑和空类隐藏，数字键不重排；新解锁项有“新”角标，选择后清除并保存在存档中。快捷键都可在设置中修改，悬停显示名称、当前键位和端口角色说明。

## 图形与加工

四种片型为外弧 `E`、内弧 `N`、下坡 `D`、上坡 `A`。相邻材料无切缝时组成连续块；块是支撑和掉落单位。上层块任意一格受到下方支撑即可整体保留，否则下落并与同层材料保留切缝。

每层短码固定 24 字符，按 0° 起顺时针十二槽排列，多层用 `:` 自底向上分隔。每槽的片型大写表示与前槽之间有切缝，小写表示相连，颜色使用小写字符，空槽为 `--`。例如无缝灰圆是 `eueueueueueueueueueueueu`。

加工保持绝对槽位；交付和筛选按整件同步旋转 30° 的整数倍匹配，电路比较器按绝对朝向精确比较。只有切割、交换和堆叠改变占位或块划分后结算掉落。染色覆盖顶层所有材料；熔炼逐层去缝，并按结果块的各槽 RGB 精确平均，黑色优先，未染色其次，无法精确对应颜色时变黑。

端口编号表示固定逻辑角色：半切机与主输入同列的出口输出槽 0–5，另一列输出槽 6–11；交换产物与各自 A/B 输入同列；堆叠输入按底、中、顶角色编号，染料为独立角色；筛选器按“匹配/其他”两个角色输出，接料时锁定路由。完整角色表见设计文档 14.2，电路端口也按固定信号角色编号。

放置时按 `H` 水平翻转端口；`V` 垂直翻转（镜像后再旋转 180°）。加工规则、物料朝向和产物角色保持不变。镜像态随建筑 code 写入存档、蓝图和吸管，不增加工具栏格子；原版合流/分流的 inverse 合并为镜像态。对称建筑的 H 无变化。一次游戏内切换或取消建筑选择会延续当前镜像态，对称建筑忽略它；吸管改用取样建筑的镜像态。非建筑放置状态的 V 保留原版蓝图粘贴；蓝图整体翻转不在本版范围。

传送带送料和建筑出口直送共用接收规则，检查输入类型、研究解锁与缓存容量。

多输入会等待材料到齐，所有非空输出都保留。超层堆叠和无效电路模板不会消耗输入。出口堵塞时形成背压；沿用原版的选区清料与拆除操作，免费清空缓存。

## 进度与经济

| 阶段 | 自动开放的主要能力 |
| --- | --- |
| M1 | 半切、顺时针 30° 旋转、图形开采、基础物流、蓝图 |
| M2 | 交换、二级隧道 |
| M3 | 双层堆叠、基础电路 |
| M4 | RGB 颜色开采、顶层染色 |
| M5 | 熔炼 |
| M6 | 三层、虚拟加工、只读分析、订单信号 |
| 自由模式 | 无限 MAM 订单与七至十级速度研究 |

每阶段五个主线目标并行，两组支线各按三项顺序推进，未完成支线跨阶段保留。已完成阶段的代表图形开启永久科研档位；旧交付不回填新档位或新订单。

科研来自支线、代表档位和 MAM 奖励，用于独立购买辅助机器及四类速度升级。辅助机器不会成为主线前置；传送、开采、加工、染色分别使用 `1 + 0.5 × 等级`，十级封顶。

中心只接收有有效用途的图形，传送带与建筑直送都在入口同步判定并记账，所有入口共享实时额度；拒收时物料留在上游形成背压。一件物料可同时计入蓝图、主线、支线、代表图形等用途。蓝图点与科研独立：开放蓝图 DN/NA/B/R/R4/R5/R6 的面值依次为 1/1/3/5/8/12/20；复制费用为每建筑 0.5 点，超链接入网费为每件 0.1 点，以整数十分之一保存，无浮点余额漂移。普通带直送中心免费。

超链接是相邻线路组成的共享物料网络，入口、线路和出口合计限 3 倍当前带速，每条输入/输出限一条带速；不同物料混合分发。入网成功只扣一次费，已付费的在途物料在余额耗尽后继续输送，中心独立检查收货资格。

## 电路与 MAM

M3 开放图形/布尔常量、传感器、显示、同类型比较、AND/OR/NOT。M6 开放整数/颜色/片型常量、取层、取槽、整数运算、选择器、寄存器、上升沿、订单源、整组订单寄存器，以及主要加工的虚拟版本。购买的辅助加工在 M6 自动获得对应虚拟节点。

无信号、布尔、整数、颜色、片型和图形分别处理。虚拟加工输出输入有效、可加工及每路有产物/图形，超层与合法空出口分开表达；实体和虚拟节点共用领域运算。

订单源整组输出有订单、关号、完整目标、需求、已交付与剩余量。订单寄存器同时锁存六项，避免混用两个订单。订单由存档种子、关号与生成器版本，从四种原料经过合法主要加工有限构造；发布后保存确切短码及历史题，恢复时保留原题。

## 多语言

跟随游戏语言，覆盖 shapez 1.5.6 的全部语言：

`en zh-CN zh-TW ja kor cs da de es-419 fr it hu nl no pl pt-PT pt-BR ro ru fi sv tr uk he`

各语言的界面、研究、建筑、节点、任务、通知和帮助共用 172 个基础文案，变体名称由本语言基础文案与角度等稳定符号组成。安装说明也覆盖全部语言。构建检查缺失键、空译文和占位符；希伯来语界面使用从右到左布局，短码保持从左到右。

## 源码与构建

在仓库根目录运行 `npm run pack -- --mod Twelvefold`，默认同时输出 `ModZips/Twelvefold.js` 与版本化 ZIP。根目录 `DefaultPath.json` 的 `modsDirectory` 可指定游戏模组文件夹，打包后自动复制 JS；配置方式见 [共用工具说明](../AfterBuildEvent/README.md)。元数据和版本见 `mod.json`，入口为 `src/main.ts`；`domain` 是纯玩法数据与运算，`game` 是 shapez 接入，`i18n` 是翻译。

建筑采用灰色机身、深色轮廓、类别强调色、十二槽动作盘和编号接口；蓝图为蓝色半透明图，工具栏按建筑生成图标。主要机器的教程图使用实际加工函数和 `drawShape` 绘制“输入 → 输出”。11 张尺寸及端口匹配的图片沿用 Shapez Industries（Sense_101）和 SQ-X（梦想天生），其余图及镜像变换自制；逐文件来源见 [assets/SOURCES.md](assets/SOURCES.md)，构建说明中的 `CREDITS.md` 也包含此清单。参考目录没有许可文件，发布前由用户确认授权；运行无外部图片下载。

完整数值和玩法合同见根目录 [NEW-MOD-DESIGN.md](../NEW-MOD-DESIGN.md)。静态检查与构建核对源码、翻译数据和单文件产物；实际游玩与界面效果仍需在游戏中确认。

## Implementation deviations

None。M3 的顺/逆 60°、顺/逆 90°均按每对合计 6 科研拆为各 3 科研，保留设计的独立购买与商店预算。
